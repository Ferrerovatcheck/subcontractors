Carrier VAT Checker

Verify the approval status of a carrier by VAT number.

PLEASE DO NOT SHARE THIS TOOL OUTSIDE YOUR ORGANISATION.

Only Ferrero approved users are allowed to use this tool.

Step 1 — Enter your access code
If you don't have an access code, you need to request one by filling out this online request form.
Step 2 — Enter carrier VAT number
Include the country code prefix (e.g. DE, NL, FR, GB, IT). Make sure there are NO SPACES, only country code and the numbers (e.g. DE1234567).
For carrier registration enquiries contact scsecurity@ferrero.com
All consultations are logged for audit purposes.
